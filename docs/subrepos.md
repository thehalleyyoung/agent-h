# Sub-repo overview

- `shell`: CLI, REPL, permissions, tools, MCP client
- `bankroll`: cost ledger and budget pressure
- `coevo`: co-evolution controller
- `homer`: delegation/sub-agent substrate
- `atelier`: skill model and seed skills
- `cartograph`: repository summarization
- `crucible`: scoring and benchmarks
- `distill`: context compaction
- `groundwork`: manifests and traces
- `kiln`: test/build execution
- `mnemos`: memory
- `manyworlds`: branching
- `rerun`, `stepback`: replay and determinism
- `adversary`, `ragdoctor`, `flowwarden`, `toolforge`, `looper`: safety, retrieval, supervision, extension, cycle checks
